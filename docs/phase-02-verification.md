# 阶段二验证记录

验证日期：2026-10-29。环境：Windows 11、Node.js 24.9.0、pnpm 12.14.0。范围以 `docs/phrase02.md` 为准。

## 已实现

- `/`：极简中文页面，工作区选择、连续对话、发送/取消、执行事件、最近任务文件变更及修改前后文本；支持刷新恢复与手机宽度布局。
- `/workspace/*`：单用户内存会话，异步启动任务、轮询、取消、切换目录和重置；同源校验、禁止缓存与 CSP nonce。保留阶段一 `/health`、`/agent/invoke`。
- `src/workspace/picker.ts`：固定 PowerShell STA 脚本打开 Windows 目录窗口，Unicode 返回协议、并发保护、超时、取消与稳定错误。用户路径不拼接到命令中。
- `src/workspace/workspace.ts`：统一实际路径检查；列目录、分段读取、字面搜索、独占创建和精确修改。完整读取授予版本，修改校验哈希与文件身份，写入串行化，已完成效果单独记录。
- `src/agent/sessions.ts`：沿用阶段一执行器与配置模型，按整轮保存 SDK 消息，最多 8 轮；128 KiB 字节上下文预算，输入预留 32 KiB，并在每次模型调用前复核。取消后等待已启动文件操作结束再释放会话。

## 离线与本机验证

- `pnpm check`：Biome、严格类型检查、13 个测试文件（164 通过、3 跳过）及构建通过。跳过项为两个仅 POSIX 的进程信号/进程组超时测试，以及当前 Windows 权限不支持创建的文件符号链接用例；实际 junction、根路径别名和硬链接用例通过。
- `pnpm smoke:phase-01`：健康接口、原有参考工具闭环、元数据日志及生产 mock 拒绝通过。
- `pnpm smoke:phase-02`：实际 HTTP 服务、页面、同源保护、临时目录选择回调、读取、修改、创建、连续任务和工作区切换通过；使用动态端口，自动关闭服务及清理目录。
- 文件工具测试覆盖 Windows 盘符、UNC、NTFS 数据流、设备名、目录穿越、链接/junction、硬链接、敏感路径排除、UTF-8/BOM/CRLF、冲突、歧义替换、非覆盖创建、输出与遍历上限、取消及暂存文件清理。
- 会话测试检查第二轮携带上一轮工具调用与结果、整轮裁剪、取消时锁定切换与并发任务、取消后的继续执行。可恢复文件错误显示工具失败，不能作为写入成功展示。
- 页面脚本测试覆盖选择取消、刷新恢复、轮询失败保持锁定、取消竞态、上下文提示与不可信文本展示；原生选择器测试使用子进程替身，不打开真实弹窗。

## 真实浏览器

使用 ego-browser 打开本机临时 mock 服务，实际操作选择工作区、发送列目录、创建文件、查看变更、刷新恢复、新会话和再次发送；页面显示实际工具结果与文件变更。390px 宽度下页面没有横向溢出，已查看桌面与手机截图。

此轮浏览器验证使用临时目录，并由测试脚本注入目录选择回调；没有自动操作 Windows 原生目录窗口。截图中的临时本机路径未写入仓库。

## Magpie 真实文件任务

显式执行 `RUN_MODEL_SMOKE=1 pnpm smoke:workspace-model`，使用现有 `workbuddy-ai/deepseek-v4.1-flash`，通过本机 HTTP API 和真实文件工具验证两轮自然语言任务。工作区为自动生成的临时目录，目录选择回调由测试注入。

1. 第一轮读取 `alpha.txt` 与 `beta.txt`，创建 `summary.txt`，修改 `beta.txt` 状态；4 次工具调用，正常完成，所有文件内容与变更记录断言通过。
2. 第二轮沿用会话，重新读取并更新前一轮创建的摘要；3 次工具调用，正常完成，摘要和未修改原文件的内容断言通过。

SDK 用量：第一轮输入 4510、输出 406、合计 4916 tokens；第二轮输入 6719、输出 459、合计 7178 tokens。未估算价格。服务与临时目录在测试结束后清理。

## 限制与未验证项

- Windows 原生弹窗的人工选择尚未验收；普通页面与选择器协议已分别验证，不能写成完整原生交互验收通过。
- 真实模型只验证上述 DeepSeek 两轮任务，不代表所有模型、Responses 协议或广泛任务质量。页面真实交互用 mock；真实模型任务经 HTTP 脚本执行，两者证据分别记录。
- 本轮未运行远程 CI；Linux 的原生目录选择明确返回不可用。普通测试不依赖真实数据库或模型。
- 文件约束属于应用层访问检查，不能对抗恶意本地进程的目录替换竞态。取消不回滚已完成文件写入；会话与最近结果只在内存中保留。
- 不支持自动创建父目录、删除、shell、任意网络工具、服务器部署、数据库持久化、任务恢复、审批、长期记忆或运行时 MCP。
