# 阶段一：最小 Agent 调用闭环

## 阶段目标

使用 Vercel AI SDK 打通「HTTP 请求 → 单 Agent 模型调用 → 参数校验与无副作用工具执行 → 结果回填 → 结构化响应与事件」，并通过确定性离线测试验证正常与失败路径。

## 构建要求

- **HTTP 接口**：新增临时、非持久化的 `POST /agent/invoke`，接收 `{ "message": "..." }`；仅接受 JSON，message 非空且不超过 8,000 字符，请求体不超过 32 KiB，非法输入返回 400。
- **响应契约**：包含 `invocationId`、实际模型标识（mock 明确标记）、`output`、`finishReason`、按发生顺序收集的 `steps` 和 `usage`；步骤包含工具名、已校验参数、状态及结果或错误摘要，SDK 未提供用量时返回 `null`。
- **执行器**：独立于 Hono，通过显式参数接收输入、模型、工具与事件回调；使用 SDK tool loop，最大步数默认 4、硬上限 8，总超时默认 30 秒，支持向模型与工具传递 AbortSignal；失败时保留已完成步骤摘要。
- **工具**：只注册一个确定性、无副作用工具（如 `lookup_reference`），使用 zod 校验 `{ key: string }`，查询固定映射，未知 key 返回 `found: false`；拒绝未注册工具，非法参数不得进入 `execute`；失败工具仅用于测试。
- **模型适配**：配置解析与厂商依赖集中在适配层，核心复用 SDK 模型类型；支持可注入 mock，`MODEL_PROVIDER=mock` 在生产环境启动时必须被拒绝；未配置真实模型时不自动调用 Gateway 或付费服务。
- **事件与错误**：以 `invocationId` 关联开始、模型步、工具请求、校验失败、工具完成 / 失败及结束事件；stdout 输出结构化元数据，默认不记录消息、Prompt、工具结果正文或模型原始响应。错误码稳定，可区分输入、配置、模型、工具、步数上限、超时和取消，响应不得泄露密钥、堆栈或服务商原始内容。
- **工程质量**：保持 TypeScript 严格模式，外部输入使用 `unknown` + zod；`pnpm check` 覆盖 lint、类型检查、离线测试与构建；测试拦截未预期网络请求，构建产物排除测试文件，同步 README / CLAUDE.md 中的实际能力、命令与错误映射。

## 构建约束

- 仅本地单用户、单进程、单 Agent；监听 `127.0.0.1`，不开放 CORS，不做认证或公开部署。
- 调用与事件仅存内存，重启即丢失；不接数据库、迁移、队列或 Worker，不实现持久化 Run、租约、恢复与审批。
- 工具不读写文件、不访问网络、不执行 shell、不写数据库；不接 MCP、动态工具目录、记忆、UI、多 Agent 或后台任务。
- 静态工具表只表示允许注册的工具，不代表已实现用户分配、allowlist 或调用时授权。
- 普通测试、CI 和 `pnpm check` 不读取真实密钥、不调用真实模型、不产生模型费用；真实模型 smoke 必须显式开启并单独记录。
- 不预建空模块、provider registry 或后续阶段接口，不声称断点续跑、exactly-once 或崩溃安全。
- 使用 Node.js 24.x、pnpm 12.14.0、LF 行尾和 `.js` 相对导入；不依赖 Docker 或全局安装，必要的新依赖使用精确版本并更新 lockfile。

## 验收标准

- [x] 干净检出后 `pnpm install --frozen-lockfile && pnpm check` 通过；离线测试无需数据库、真实密钥或网络，未预期请求会失败。
- [x] 覆盖无工具调用路径，以及 mock 发起一次工具调用、参数校验、工具仅执行一次、结果回填和生成最终文本的完整路径。
- [x] 非法工具参数不执行工具；未注册工具被拒绝；工具抛错有明确摘要并终止循环，无无限重试。
- [x] 达到步数上限、超时或 Abort 时及时结束，结束原因明确，取消信号传递到模型与工具，无悬挂任务；中途失败保留已完成步骤摘要。
- [x] 空 body、非 JSON、超限 body、空或超长 message 返回 400；错误响应不泄露内部内容。
- [x] 构建后以开发 mock 配置启动，`/health` 与调用闭环均可用，响应标记 mock；生产环境拒绝启动 mock。
- [x] 日志可按 `invocationId` 关联步骤，默认不含对话与结果正文；文档与实际能力一致，无超出本阶段范围的实现。
- [x] 留存实际命令、通过 / 失败结果与未运行项；真实模型 smoke 未执行时明确记录“未运行”。
