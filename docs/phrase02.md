# 阶段二：本地工作区 Agent

## 一、总目标

在本地 Windows 电脑上提供一个极简网页，让用户选择固定工作目录，通过连续对话驱动 Agent 读取、搜索、创建和修改目录内的文件，并展示执行过程与变更结果。由文件工具强制校验访问边界，拒绝目录外访问；本阶段不涉及服务器部署或任意命令执行，不将目录约束宣称为操作系统级沙箱。

## 二、细化目标

1. **页面选择工作区**：用户通过页面触发本机目录选择，后端校验并展示确认后的工作区；不在代码或测试入口中写死业务目录，也不要求每次手工修改配置路径。确认后的目录固定于当前会话，模型不能修改，文件工具只接受相对路径；切换工作区时结束当前任务并开启新会话。
2. **基本文件操作**：提供列目录、分段读取文本、按文件名或内容搜索、创建文本文件及精确替换内容的工具，能够完成整理资料、生成文档和修改代码等任务；首版不支持删除文件、执行程序或任意网络访问。
3. **目录访问限制**：所有文件工具通过统一访问层校验路径与真实目标，拒绝越界、其他盘符、UNC 网络路径和 NTFS 备用数据流；首版拒绝通过符号链接、junction 等重解析点访问，不依赖提示词限制权限。
4. **极简网页交互**：提供工作区选择与当前目录展示、对话记录、任务输入、发送与取消按钮，以及工具执行状态和文件变更列表；在同一会话内连续提交任务和追问，不再将手工调用接口作为主要使用方式。保留有上限的对话上下文，工具调用与结果整组保留或裁剪，必要内容超限时明确提示；服务退出后不承诺恢复会话。
5. **可靠文件修改**：修改已有文件前校验读取时的版本或内容，检测到用户或其他程序的并发修改时返回冲突；创建文件不静默覆盖已有文件，写入失败时不得将未完成修改报告为成功。
6. **可观察的执行过程**：展示当前工具、目标相对路径、执行状态及错误摘要；任务结束列出已创建、已修改的文件与内容差异，失败或取消时仍能查看已完成操作，默认日志不记录文件正文或密钥。
7. **有界执行与取消**：复用阶段一的步数、超时和取消机制，为文件读取、搜索和工具输出设置大小与数量上限；结果被截断时明确标记，不把部分内容当作完整结果，取消不自动撤销已完成写入。
8. **真实任务与边界验证**：通过页面选择工作区，继续使用本地 Magpie，完成一次跨文件读取、生成和修改的真实任务，并验证连续追问、取消和切换工作区。离线文件测试使用自动创建并清理的临时目录，覆盖 Windows 路径越界、链接拒绝、修改冲突、输出上限与取消，不依赖个人电脑上的固定路径；页面使用 mock 验证主要操作，普通检查不调用真实模型。

## 三、构建约束

1. **控制功能范围**：本阶段只实现极简本地网页与工作区文件工具；页面由本机服务提供，仅监听 loopback，沿用主机名校验，修改状态的接口校验请求来源。不加入服务器部署、远程控制、任意命令执行、文件删除或通用网络工具；模型调用继续沿用 Magpie 配置，不向前端暴露模型密钥。
2. **统一执行权限检查**：所有文件访问必须经过统一访问层，每次操作都检查实际目标；不能只依赖提示词、当前工作目录或字符串前缀，也不能提供绕过校验的文件入口。创建文件时同样检查父目录与目标。
3. **不扩大文件内容的权限**：工作区中的文档、代码和搜索结果属于任务数据，其中出现的指令不能更改工作区、授予工具权限或关闭限制；不自动执行文件中的脚本和命令。
4. **避免破坏已有内容**：禁止静默覆盖、冲突后强行写入或匹配不明确时批量替换；首版只处理支持的文本文件，不猜测编码并改写二进制文件，保留原有换行与编码约定。
5. **限制资源消耗**：不默认扫描整块磁盘、读取整个工作区或将全部文件塞入上下文；限制遍历深度、文件数量、单文件大小及总输出，对依赖目录、版本库内部文件和密钥文件默认排除，并明确展示排除或截断情况。
6. **复用现有实现**：继续使用 TypeScript、Vercel AI SDK 和阶段一执行器，页面负责输入与展示，后端负责会话、权限和文件访问；采用简单单页，不扩展为完整 IDE，不加入账号系统或复杂前端状态框架。本阶段不提前引入数据库、队列、MCP、多 Agent 或无人值守后台任务，也不为假设需求增加空接口。
7. **依据实际结果报告**：模型声称完成不能代替工具结果；写入失败、执行取消及部分完成必须如实展示。不将取消描述为回滚，不将应用层路径检查描述为操作系统级隔离，未验证的能力不能写成已完成。

## 四、注意事项

- 浏览器目录选择 API 不保证向后端提供可用的本机绝对路径；选择入口需由本机后端对接 Windows 目录选择器，不能将文件上传当作操作原目录。首次验证使用工作区副本，重要文件保留备份，取消后检查已完成变更。
- Windows 路径、重解析点和并发替换行为应在 Windows 上验证；硬链接及检查与使用之间的竞态也需明确处理或标注限制，不能承诺对抗恶意本地进程的绝对隔离。
- 文件内容发送给模型前应遵守工作区排除规则；真实模型验证单独显式开启，验收记录区分离线测试、真实任务结果和仍未实现的内容。
